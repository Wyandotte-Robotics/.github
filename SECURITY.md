# Security and privacy

## Reporting a problem

If you find a security problem in one of our repositories, or find personal information, a password or a key that shouldn't be here, please **don't open a public issue**.

Instead, either:

- use **Report a vulnerability** on the repository's **Security** tab, if it's turned on, or
- email **hello@wyandotterobotics.com**.

We're a volunteer-run student team, so we'll do our best to reply within a few days.

## For team members

If you accidentally commit a password, key or someone's personal information, tell a coach right away. Deleting the file in a new commit isn't enough; the old version is still in the history, so a coach needs to remove it and change any exposed password.
