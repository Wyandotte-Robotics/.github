# .github

Organization-wide defaults for [Wyandotte Robotics](https://github.com/Wyandotte-Robotics).

| File | What it does |
| --- | --- |
| [`profile/README.md`](profile/README.md) | The public page at github.com/Wyandotte-Robotics |
| [`CONTRIBUTING.md`](CONTRIBUTING.md) | How we branch, commit, review and keep things private |
| [`CODE_OF_CONDUCT.md`](CODE_OF_CONDUCT.md) | How we treat each other, and how to report a problem |
| [`SECURITY.md`](SECURITY.md) | How to report a leaked password, personal information or a security problem |
| [`SUPPORT.md`](SUPPORT.md) | Where to ask for help |
| [`FUNDING.yml`](FUNDING.yml) | The "Sponsor" button on every repo, linking to our fundraising page |
| [`ISSUE_TEMPLATE/`](ISSUE_TEMPLATE) | Bug report and task forms |
| [`PULL_REQUEST_TEMPLATE.md`](PULL_REQUEST_TEMPLATE.md) | The checklist on every pull request |

Any repository in the organization that doesn't have its own copy of one of these files uses the version here.

The members-only welcome page lives in the private [`.github-private`](https://github.com/Wyandotte-Robotics/.github-private) repository.
